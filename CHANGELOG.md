# Changelog

## 1.0.0

First release of Lucky's Better Wardrobe, a continuation of Better Wardrobe and Transmog by SLOKnightfall.

### Added

- Your existing Better Wardrobe collections, saved sets, hidden appearances, and settings carry over automatically the first time you log in.

### Fixed

- Transmog sets no longer drop slots when applied.
- Set filters now use the correct tab, so the right sets are shown.
- The saved sets list now displays reliably.
- Restored missing difficulty variants and Midnight expansion sets.
