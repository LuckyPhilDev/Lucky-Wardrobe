# Changelog

## 1.0.0

First release of Lucky's Better Wardrobe, a continuation of Better Wardrobe and Transmog by SLOKnightfall.

### Added

- Your existing Better Wardrobe collections, saved sets, hidden appearances, and settings carry over automatically the first time you log in.
- Sort Sets and Extra Sets by completion, with the closest sets first and larger sets prioritised when they need the same number of pieces.

### Fixed

- Transmog sets no longer drop slots when applied.
- Set filters now use the correct tab, so the right sets are shown.
- The saved sets list now displays reliably.
- Restored missing difficulty variants and Midnight expansion sets.
- Item tooltips show set completion and the appearance preview again.
- Set completion counts no longer error, so tracked sets and the Collection List fill in properly.
- The dice button is back on the transmog vendor's preview.
- Saving, renaming, and loading your own outfits works again.

### Removed

- Set collection chat alerts, and the set name and collected count toggles at the vendor. None of them ever did anything.
