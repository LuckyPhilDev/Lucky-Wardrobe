# Changelog

## 1.4.1

### Added

- Shift-right-click an appearance for its Wowhead address, in a box ready to copy into your browser. The pieces listed on a set work too, as do appearances you have not collected yet. (Thanks for the suggestion Rubyurek)

## 1.4.0

### Added

- Item tooltips now have their own settings section. Choose whether a tooltip tells you that you have already collected the appearance, lists the sets the item belongs to, and shows a model wearing it. The first two could not be turned off before.

### Removed

- The Ignore Class Restriction Filter option has been taken out while it gets a proper look. Sets and appearances follow your class again for everyone, including anyone who had the option switched on.

### Fixed

- Item tooltips work again in patch 12.0. They were throwing an error that stopped the collected line from appearing at all.
- The Custom Sets tab no longer errors when you have both a saved outfit and a Blizzard custom set, and those saved outfits show their names on tooltips again.
- Renaming a saved outfit starts from its current name, and Save stays greyed out until you actually change it.
- Marking a set as a favourite no longer errors when the set has no base version.
